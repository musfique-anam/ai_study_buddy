# 🧠 AI Study Buddy

An AI-powered study assistant that uses **Computer Vision and Deep Learning** to monitor study sessions, analyze focus levels, detect drowsiness, and provide productivity insights through an interactive dashboard.

---

## 🚀 Project Overview

AI Study Buddy is a real-time productivity monitoring application designed to help students improve their study habits.

Using a webcam, the system analyzes facial expressions, eye movements, posture, and user behavior to estimate focus levels and provide alerts when signs of distraction or fatigue are detected.

The application also stores study session data and provides a dashboard for analyzing focus trends over time.

---

## ✨ Features

### 🎥 Real-Time Focus Monitoring
- Webcam-based user monitoring
- Real-time face analysis
- Focus level estimation

### 😴 Drowsiness Detection
- Detects signs of tiredness using eye and facial features
- Provides audio alerts when drowsiness is detected

### 🧍 Posture Monitoring
- Detects poor sitting posture
- Encourages maintaining a healthy study position

### 😊 Emotion & Distraction Detection (Pro Mode)
- Analyzes facial emotions
- Identifies possible distraction states

### ⏱️ Pomodoro Study Mode
- Built-in 25-minute Pomodoro timer
- Helps maintain productive study sessions

### 📊 Performance Dashboard
- Stores previous study sessions
- Displays:
  - Total study time
  - Focus percentage
  - Alert count
  - Focus trends
